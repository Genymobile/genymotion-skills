# Repository Invariants

Facts that more than one file of this repository relies on. Load this file before reading a diff.

- `live`: a required check on the default branch runs the pinning test, or the artefact that stands in for one.
- `pending`: written for the named unmerged branch.
- `gap`: relied upon, but no test that gates the merge enforces it.

The pinning tests are in `tests/fanout/run-tests.sh`. The workflow `.github/workflows/fanout-tests.yml` runs them.
